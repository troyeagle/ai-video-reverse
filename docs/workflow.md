# 实际工作流程与复现

## 1. 先确认视频，而不是从标题猜内容

从B站公开API读取目标BV号的元数据：

```text
BV号：BV1MssN6ZE1v
CID：43663101273
作者：Alpha茶水间
标题：严查税、补社保只是序章：土地财政退潮后，钱从哪里来？
单P；标称625秒
```

检查当前工具：FFmpeg、FFprobe、Swift和uv可用；初始Python环境未安装语音识别库。先查字幕入口，同时从DASH播放地址下载视频流和最高带宽音频流。请求携带浏览器User-Agent及目标视频的Referer，优先使用可用的CDN镜像。

下载后以FFmpeg进行流复制合并，不再次编码。FFprobe确认实际视频为852×480、H.264/AAC，时长624.576秒，文件17,947,452字节。

## 2. 检查字幕是否真的属于目标视频

匿名字幕接口提示需要登录。复用现有Chrome登录态读取字幕；两次结果虽然成功返回，但分别是汽车导航和电脑水冷内容，明显与财政主题不符。

第一份返回只有73条、结束于475.8秒；另一份有1476条、结束于2937.16秒。内容与时长均不能作为目标视频讲稿。原始错误返回移到 `字幕接口错误返回/`，作为本地排错证据，不进入文章或Slides数据。

没有把这个异常归因于已确认的B站服务端问题：本次只验证了返回结果错误，未证明具体原因。

## 3. 使用本地ASR完整识别音频

建立Python 3.12环境，安装 `mlx-whisper==0.4.3`，模型为 `mlx-community/whisper-large-v3-turbo`。明确语言为中文，并用财政相关专有名词作为初始提示。

首次uv运行因默认缓存位置超出工作区被阻止；按工具权限要求授权执行。后续依赖及模型缓存放到案例目录。MLX在沙箱中报告没有Metal设备，随后以获准的本地GPU访问执行识别。

保留原始输出：`语音识别.json`、`语音识别.srt`、`语音识别原文.txt`。记录中的本次完整识别耗时为43.2秒。

识别结果结尾产生了超出真实音频时长的重复文字。校订版本删除623.92秒后无依据的重复段，保留实际片尾口播。247条校订段覆盖0.00—623.92秒。

## 4. 用视频画面复核数字和错字

每15秒提取参考帧，以Swift Vision识别标题、图形文字及底部字幕；对具体错字另取精确时间帧。系统文字识别同样需要可用的本地系统识别服务。

本次复核的重要数据包括：5000亿元、2.8万亿元、2.3万亿元、4.1万亿元、24.4%、34.1%、13.9%、12.9%、约70%、199万亿元、6.2万亿元、600亿元及超3万亿元。

校订了“购买力平价”“工资条”“征税视野”“实收口径”“税基”“低显性税负”“社保实缴”等错字。文章补充标点、段落、小标题，保留原作者论述；含说明的Markdown约3861字。

## 5. 识别页面与内部演示阶段

先查看各标题页的参考拼图，确定配色、构图和图形类别。视频有19个主要标题；将其中重要的数字出现、图表变化和资金流向展开拆成32页。

通过仅裁剪顶部标题区域的画面变化检测辅助定位切页：

```text
crop=852:76:0:44,select='gt(scene,0.009)',showinfo
```

使用 `-fps_mode vfr`，检查FFmpeg返回码并解析 `pts_time`。连续的标题渐变会产生多个候选时间，须结合画面聚类和人工检查；检测输出不能直接等同于最终页数。

初始ASR第一段长23.2秒，跨越13.8秒处的前两页切换。因此单独识别前64秒，启用 `word_timestamps=True`，以逐字时间拆成合理讲稿片段。

后续原句按时间中点分配到页面，临近短句合并为阅读行；每行通常不超过78字符或10秒。32页共81条讲稿记录，构建脚本校验所有语料顺序一致、恰好分配一次。少量跨切页的句子归入主要所在页。

## 6. 用独立元素重建页面

- 原视频米白底、深绿文字、绿色图形基座、金黄色钱币及橙红强调作为视觉依据。
- 银行、钱袋、房屋、工厂、购物车、票据、人物、电网、港口等以SVG几何图形重绘。
- 图表、标题、标签、资金流向和税基边界都是独立元素。
- 默认文字依次渐入；切页有渐出与渐入；柱状图增长、连线绘制、钱币沿路径移动。
- 分步模式按 `data-order` 控制内容展开，重播时重置动画。
- 下拉、目录、搜索、滑条、快捷键和URL片段 `#slide=N` 都可以选页。
- 原声播放使用从源音频流复制封装的 `narration.m4a`，同步切页并高亮右侧原句。

网页、数据和源文件同时交付。HTML内嵌CSS、SVG、JavaScript及讲稿，直接以 `file://` 打开，不依赖运行时网络请求加载演示内容。

## 7. 实际浏览器验证及打包

在后台Chrome标签页验证32页，检查图形边界、讲稿对应、目录搜索、按钮、快捷键、分步展开、动画和原声。标签页隐藏时动画与媒体加载会被暂停或降速，测试时按browser-use技能临时启用焦点模拟，结束后在 `finally` 中关闭。

逐页截图仅用于本地视觉验证。修正了基座遮挡标签、绝对定位提示变成竖排、结尾页拥挤、钱币盖住财政标签等问题。390px手机视口确认无横向溢出，讲稿位于演示区下方。

离线包包含HTML、原声、页面数据、使用说明、逐页讲稿及可编辑源文件。运行打包内的 `source/rebuild.py` 后，HTML哈希与交付版本相同；ZIP完整性检查通过。交付ZIP为12,376,007字节。

## 8. 迁移后的常用命令

仅重建和验证网页：

```bash
python3 scripts/build_slides.py
python3 scripts/validate_case.py
```

重新创建ASR环境并识别音频（从工程根目录运行）：

```bash
uv --cache-dir cases/BV1MssN6ZE1v/.uv-cache venv --python 3.12 cases/BV1MssN6ZE1v/.asr-venv
uv --cache-dir cases/BV1MssN6ZE1v/.uv-cache pip install --python cases/BV1MssN6ZE1v/.asr-venv/bin/python -r requirements-asr.txt
cases/BV1MssN6ZE1v/.asr-venv/bin/python cases/BV1MssN6ZE1v/transcribe.py
```

如果当前已有迁移过来的旧环境，先按uv的环境管理流程重新创建。运行ASR需要本地媒体、模型及Metal GPU；文件系统或GPU被沙箱阻止时，按当前执行工具的权限规则处理。
