# 土地财政退潮后，钱从哪里来？ · 交互 Slides

打开 `index.html` 即可使用。网页包含32张可选幻灯片，按原视频的19个主要标题和内部图表变化拆分。

## 使用

- **自由选页**：使用左上角下拉框、“全部页面”目录、底部滑条或左右方向键。
- **页面目录**：显示所有页面的矢量预览，可搜索标题或原视频讲稿。
- **重播动效**：重新演示本页的文字渐入、柱状图增长和资金连线。
- **逐步演示**：打开后，用“展开一步”逐步显示本页内容；空格键也可展开。
- **自动演示**：按原视频的时间范围依次翻页，不播放声音。
- **播放原声**：播放原视频音频，自动切页并高亮右侧讲稿。选页时音频会定位到对应位置；点击讲稿某一行可以播放该段。
- **复制讲稿**：复制当前幻灯片对应的原视频文字内容。
- **全屏**：进入幻灯片演示模式。普通模式下，讲稿表位于右侧；窄屏下移动到幻灯片下方。

快捷键：左右方向键翻页，空格展开或进入下一页，`R` 重播动效，`G` 打开目录，`Home` 第一页，`End` 最后一页。

## 文件

- `index.html`：完整网页，文字、CSS、SVG图形、交互脚本和讲稿数据已内嵌。
- `narration.m4a`：从原视频无损封装提取的原声。与网页放在同一文件夹，即可播放。
- `slides-data.json`：32页的标题、演示阶段、原视频时间范围和对应讲稿。
- `页面与讲稿对照.md`：可以独立阅读的逐页讲稿。
- `source/`：独立的样式、绘图、交互、图标与网页模板源文件。编辑源文件或数据后，可运行 `python3 source/rebuild.py` 重新生成网页。

网页可以离线打开，不需要安装运行环境。HTML单独复制后仍可使用选页、图形动画和讲稿功能；播放原声时需要同时复制音频文件。
